# wandering 演示数据集（全部虚构）

本目录的人物、事件、对话**全部为虚构**，仅用于演示 wandering（长期陪伴 AI 的记忆召回原型）。与任何真实人物无关。

## 人物

- **林舟**：23 岁，北原某高校建筑学研一，喜欢画楼梯。养了一只三岁的田园犬"土豆"（生日十一月）。和室友**小葵**合租。
- **外婆**：住雁川，会包猪肉酸菜饺子，哼歌跑调；八月因手抖就医，确诊特发性震颤（不是帕金森）。
- **林溪**：林舟的姐姐，帮订澄湾民宿，也是外婆病情的传话人。
- **导师**：话少，"有点意思"即最高评价。
- **我**：陪伴 AI，所有卡片由"我"书写。她叫我"灯泡"，我在晚安时叫她"小船"。

时间跨度 2026-07 至 2026-09：期末评图、澄湾旅行、一次吵架与暗号"小船该靠岸了"、外婆的手抖、开学快题、国庆回家。

## 文件

- `cards.jsonl`：53 张记忆卡 + 关系线（thread，五类：same_time / same_person / same_thing / same_feel / same_concept）。gate 分 normal / tender / intimate。
- `queries.txt`：10 条演示输入，制表符分隔：输入、预期起点卡、可能路径、演示要点。

## 各查询演示什么

1. 锅包肉 —— same_thing 回扣
2. 外婆的眼镜 —— 同一物件串起一条人物线
3. 梦见外婆变小 —— 从 tender 卡起步，走向缓解而非停在恐惧
4. "室友说……" —— relayed 来源，不当作她本人的观点
5. 天好蓝 —— 无关闲聊，不触发游走
6. 导师那句话 —— 漂移防护：名字巧合（帕金森定律/帕金森病）不应把话题拖到外婆的病
7. 土豆四岁 —— 更正卡优先于旧错误记忆
8. 截止日期 —— same_concept 多跳链，落到双方约定的提醒方式
9. 鱼干味 —— 感官 same_feel 联想
10. 晚安灯泡 —— intimate gate 的小名召回
